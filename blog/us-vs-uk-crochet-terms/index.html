US vs UK Crochet Terms: Read the Pattern Before You Start

Check US and UK crochet terms, compare three common stitch names, and make a simple pattern note before your first row.

AppMaven StudioOctober 18, 2026Crochet basics

In this guide

  1. Find the terminology system
  2. Three stitch names to compare
  3. Try a pattern-reading example
  4. Make a reusable project note

You open a crochet pattern and see dc. Before working the first stitch, find out which terminology system the designer uses. The same abbreviation can describe a different stitch in a US pattern and a UK pattern.

This guide is a reading check for ordinary crochet patterns. It is not a stitch tutorial or a replacement for the designer’s instructions.

Find the terminology system

Look in the introduction, materials list and abbreviation key for a statement such as “US crochet terms” or “UK terminology.” Read the special-stitch definitions too. A designer may define an abbreviation that does not appear in a general reference.

If the system is missing, ask the designer before starting. Do not decide from the designer’s location, the shop currency or one familiar-looking abbreviation.

Three stitch names to compare

These three common pairs refer to matching stitches under different names:

US patternUK pattern
Single crochet (sc)Double crochet (dc)
Half double crochet (hdc)Half treble (htr)
Double crochet (dc)Treble (tr)

Use this small comparison to check the system, then return to the pattern’s own key. It is not a conversion chart for every stitch or a guide to Tunisian crochet.

Try a pattern-reading example

Original reading example: imagine a practice note that says “work 6 dc.” In a US-terms note, that means six US double crochet stitches. In a UK-terms note, it means six UK double crochet stitches, which correspond to US single crochet.

The number six has not changed, but the stitch has. Translating a label does not tell you where to place a stitch, how to turn or whether a turning chain counts. Check those details separately in the actual pattern. This short example is not a complete pattern to crochet from.

Make a reusable project note

Before you begin, write a short note you can find again after a break:

  • Pattern: title, designer and a link to your own copy.
  • Terms: US or UK, with the page or section where that is stated.
  • Special instructions: where to find the designer’s stitch key and turning-chain rule.
  • Next step: the row or round you will work next.

For example: “Practice project — UK terms — stitch key on page 2 — next: row 4.” These are suggested note fields, not requirements from a standards body. Keep your pattern available while you work.

Terminology is one check; tool sizing is another. Before choosing your hook, read our guide to checking crochet hook sizes in millimetres.

Keep your project notes together

Paper notes work well. If you prefer a phone, our StitchCount Android app includes project notes alongside row and repeat counters. Choose whichever method helps you return to your own pattern with a clear next step.
