Crochet Gauge: Measure Your Swatch and Choose the Next Hook

Compare a crochet swatch with the pattern gauge, understand more or fewer stitches per inch, and record each hook-size trial clearly.

AppMaven StudioOctober 18, 2026Crochet basics

In this guide

  1. Read the gauge instructions
  2. Compare the same measurement
  3. Choose a hook to try next
  4. Work through a numerical example
  5. Record the trial before restarting

A hook size on a pattern gives you a starting point. A gauge swatch lets you compare the fabric you make with the pattern’s target before committing to the project.

The useful question is specific: how many stitches and rows fit into the length stated in this pattern? Keep the two counts separate.

Read the gauge instructions

Find the target stitch count, row count, measurement length and stitch pattern. Make the sample using the specified yarn, hook and stitch pattern, following any additional preparation instructions in the pattern.

Do not substitute a favourite stitch for the stated sample. If the pattern leaves the sample method unclear, ask the designer before relying on your result.

Compare the same measurement

Count stitches and rows carefully over the stated length. Record the units alongside the numbers. Compare stitches with stitches and rows with rows; a matching stitch count does not establish that the row count also matches.

Use the measurement system given by the pattern. In exact conversions, 4 inches equals 10.16 cm, so do not silently treat a 4-inch sample and a 10-cm sample as identical. The arithmetic examples below all use centimetres.

Choose a hook to try next

Stitch-count check over the same length: more stitches than the target suggests trying a larger hook; fewer suggests trying a smaller hook. Make a new swatch and measure again.

A new hook is a trial, not a promise of fit. Recheck both stitch and row gauge. If they point in different directions or one still differs, consult the pattern’s guidance or designer before changing the project instructions.

Work through a numerical example

Original arithmetic example: a fictional practice pattern calls for 20 stitches over 10 cm. Your sample has 22 stitches over that same 10 cm. That is 2.2 stitches per cm rather than the target 2, so try a larger hook and measure a new sample.

To see why the difference matters, imagine a plain section containing 100 stitches. At 2 stitches per cm, the calculated width is 100 ÷ 2 = 50 cm. At 2.2 stitches per cm, it is about 45.45 cm. This is a simplified arithmetic illustration, not a garment-sizing instruction: borders, shaping and the actual pattern still matter.

If your sample instead contains 18 stitches over 10 cm, it has fewer stitches over the same length. Try a smaller hook, make another sample and check again. Do not choose the final hook from either calculation alone.

Record the trial before restarting

Use a separate line for each attempt: hook in mm → yarn and stitch pattern → measured length → stitch count → row count → next action. This note format is an editorial suggestion, not a required standard.

For the fictional trial above: “4.0 mm → specified sample stitch → 10 cm → 22 stitches → row count still to check → try a larger hook.” A missing row count remains missing; do not fill it from the stitch count.

Need to compare hook labels first? See why the millimetre size is the useful reference. Keep each swatch result until you have decided which sample meets your pattern’s requirements.

Keep your project notes together

Paper notes work well. If you prefer a phone, our StitchCount Android app includes project notes alongside row and repeat counters. Choose whichever method helps you return to your own pattern with a clear next step.
